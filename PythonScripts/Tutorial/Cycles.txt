Для того чтобы сделать бесконечный цикл нужно использовать while.
Пример скрипта:

while True:
  print("Text")

Этот скрипт бесконечно и очень быстро будет выводить Text.
Для цикла можно сделать задержку, но для этого нужно использовать библиотеку time:

import time

while True:
  time.sleep(0.5)
  print("Text")

Этот скрипт будет каждые пол секунды выводить Text.
Если ты хочешь повторить действие несколько раз то используй for итератор и функцию range:

for num in range(10):
    print(num + 1)

Этот скрипт будет повторяться 10 раз. num с самого начала начинается на 0
