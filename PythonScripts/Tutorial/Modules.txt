В Python есть множество модулей, которые облегчают работу или дают больше возможностей. Чтобы их использовать вам нужно использовать import <libraryName>
Однако если в вашем экзекуторе не установлена библиотека или модуль, то вам выведет ошибку 
Чтобы установить библиотеку вам нужно запустить следующее: pip install <libraryName> (если вы устанавливаете в командой строке)
Вот пример использования модуля:

  import time

  time.sleep(1) # Создаёт задержку потока
  print("Execute") # Это запуститься через секунду

Но ты также можешь загрузить модуль с собственным именем переменной с помощью __import__

  module = __import__("math")
  print(module.pi)

Ты можешь проверить наличие модуля с помощью try:

  try:
    import time
  except ImportError:
    print("Модуля нет")
  else:
    print("Модуль есть")
  
Для модулей есть функция from. Она позволяет взять элемент из модуля не загружая сам модуль:

  from math import pi
  num = pi
  print(num) # 3.1415...
  
У модулей есть атрибуты как у функций. Они похоже обозначаются
Пример: 

  module = __import__("time")
  print(module.__name__) # time
  
? Вот список метаданных у модулей: {
  __name__ – имя модуля
  __class__ – просто класс (выведет <class 'module'>)
  __dict__ – получает таблицу словарь с информацией об модуле
  __doc__ – задокументированное описание модуля
  __loader__ – место где загружается модуль
  __spec__ – получает loader, name и origin
}
