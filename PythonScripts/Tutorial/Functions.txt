Чтобы создать функцию нужно использовать def, а чтобы запустить её нужно ввести её имя и ():

def test():
  print("Test")

test() # Выводит Test

Для функции можно использовать параметры:

def test(text):
  print(str(text))

test("Testi") # Выводит Testi

А также можно использовать return чтобы функция возвращало что-то. Все что находится дальше return просто игнорируется:

def test(num1, num2):
  return num1 + num2
  print("Ye") # это попросту игнорируется

print(test(2, 4)) # 6

! Вызывать функцию в самой себе лучше не стоит. Это вызовет рекурсию и возможно сильную нагрузку на устройство
! Использовать итерацию на функцию нельзя. Можно только если она возвращает тип данных которые позволяют это делать (например string)
В Python очень просто можно получать подробную информацию об функциях:

def test():
  return 1

print(test.__name__) # test

? Вот все средства: {
  __name__ – получает имя функции
  __code__ – получает то где расположена функция
  __module__ – получает имя модуля в котором расположена функция
  Есть ещё и __qualname__, __doc__, __annotations__, __defaults__, __kwdefaults__, но я не знаю, что они делают
}

Также в Python есть так называемая lambda. С помощью неё ты сможешь сделать короткую анонимную функцию
Она нужна чтобы не тратить время на создании новой функции
Пример:

f = lambda x: x * 2
print(f(4)) # 8
