В Python существует функция globals(). Это довольно мощная функция
С помощью globals ты можешь изменять глобальные переменные и добавлять переменные которые ты не обозначал в скрипте
Пример:

x = 1 # теперь это глобальная функция
print(x) # 1
globals()["x"] = 3
print(x) # 3

Если ты попробуешь изменить глобальную переменную в функциях, то она изменится только в локальном (функции) окружении

x = 3
def test():
    x = 2 # это локальная x

test()
print(x) # 3

Для таких случаев существует global. Он обозначает что нужно брать функцию именно в глобальном окружении
Вот как это используется:

x = 3
def test():
    global x
    x = 2 # это уже не локальная функция

test()
print(x) # 2
