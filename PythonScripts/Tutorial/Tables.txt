Для обозначения таблиц нужно использовать квадратные или фигурные скобки, а чтобы разделять элементы нужно использовать запятую или точку с запятой:

tabl = ["A", "B", "C"]

Таблицу можно сделать как в первом варианте, так и в виде словаря. Чтобы ставить значение индексам нужно использовать :=

tabl = {
  A := 1,
  B := 2
}
print(*tabl) # 1 2

Если ты хочешь распаковать таблицу, то ты можешь использовать звёздочку:

tabl = ["A", "B", "C"]
print(*tabl) # A B C

Для таблиц можно использовать итерацию:

tabl = {"A", "B", "C"}
for i in tabl:
    print(i) # очерёдность рандомная (A B C)

tabl = {A := 1, B := 2, C := 3, "И"}
for i in tabl:
    print(i) # очерёдность уже не рандомная (1 2 3 И)

Ты можешь использовать квадратные скобки чтобы узнать параметр, но тогда нужно использовать квадратные скобки для таблицы:

tabl = [
  A := 1,
  B := 2
]
print(tabl[0]) # 1
