Для обозначения таблиц нужно использовать скобки, а чтобы разделять элементы нужно использовать запятую или точку с запятой
Но скобки означают разное: [] – список (list), {} – словарь (dict), () – кортеж (tuple)
Вот как они отличаются друг от друга: {
  [] – упорядочный, изменяемый (можно добавлять или изменять элементы), используется как массив (типо [1, 2, 3, 4]), поиск элементов по числовым индексам
  Методы для list:
    • list.clear() – очищает все элементы в таблице
    • list.sort() – сортирует все элементы (числовые по нарастающему, буквы по нарастающим ASCII кодам)
    • list.insert(index: number, value: variant) – добавляет новый элемент по индексу
    • list.remove(element: variant) – удаляет элемент
    • list.count(element: variant) – считает сколько всего есть таких элементов
    • list.reverse() – меняет все элементы местами
  () – упорядочный, неизменяемый (нельзя изменять или добавлять элементы), используется как массив (типо (1, 2, 3, 4)), поиск элементам по числовым индексам
  ? Ты не можешь изменять элементы в кортеже, но ты можешь изменить саму таблицу
  Методы для tuple:
    • tuple.index(value: variant) – какой числовой индекс у  этого индекса
    • tuple.count(value: variant) – сколько содержится таких элементов в таблице
  {} – ключ с поставленным именем, изменяемый, неупорядочный, использовать как словарь (типо {"a": 4, "b": 5}), поиск элемента по индексам (тип должен быть строкой), типо table["a"]
  Методы для dict:
    • dict.keys() – получает все ключи у словаря
    • dict.values() – получает все значения
    • dict.items() – подробно получает как обозначали ключи
    • dict.clear() – очищает всю таблицу
}

Если ты хочешь распаковать таблицу, то ты можешь использовать звёздочку
? В словарях это просто показывает ключи

tabl = ["A", "B", "C"]
print(*tabl) # A B C

\\ Про dictionary
Для таблиц можно использовать итерацию:

tabl = {"A", "B", "C"}
for i in tabl:
    print(i) # очерёдность рандомная (A B C)

tabl = {A := 1, B := 2, C := 3, "И"}
for i in tabl:
    print(i) # очерёдность уже не рандомная (1 2 3 И)
    
Для того чтобы узнать про элементы в словаре с помощью итерации нужно уже использовать два значения:

dict = {"A": 1, "B": True, "C": 2}
for key, value in dict.items():
  print(key, value)
